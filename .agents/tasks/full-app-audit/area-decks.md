## 0. Headline findings (read these first)

1. **The Curve view is hidden in the Workbench and has been since 2026-08-19.** It is the third option of a layout switch (Free-form / Piled / Curve) in a toolbar. The deck page's Workbench tab turns that toolbar off (`showToolbar={false}`), so a user cannot reach Curve (or Piled) from the deck page. It is reachable only from the AI "brew a new deck" page, which is itself switched off. Even if the toolbar came back, Curve would show every card in the "0" column, because the Workbench feeds the canvas `cmc: 0` for every card. No note records the owner's "not useful" judgement; the only notes are the generic "Audit Workbench, Analysis" item (UX-13) and the parked "mana-curve slider" (O-003). Details: section 1.1 and R-01.
2. **The Workbench tab is half-built in other ways too.** Dragging a card to another category calls a URL that does not exist, so nothing is saved. Card positions are not saved anywhere (reset on every visit). [Confirmed: `src/components/WorkbenchTab.tsx`]
3. **"Mana curve" exists in three separate places.** The left rail's chart (live, built 2026-11-19 to 11-22, approved), a chart inside the Analysis tab (older), and the Workbench Curve layout (hidden). Only the rail one was designed on purpose.
4. **Upgrade tab is a dead-end that can erase its own data.** The "Refresh" button deletes the deck's stored suggestions and writes an empty list while showing "Analysis refreshed". The engine that makes suggestions is a command-line script that reads an old local SQLite file, not the hosted database. Decision D-036(a) says a failed refresh must keep the previous suggestions. Known and written down in two contracts, still unfixed. [Confirmed: `src/app/api/decks/[id]/upgrade/refresh/route.ts`]
5. **Strategy tab has a button that pretends to work.** "Sync to Archidekt" asks for confirmation, then shows "Categories synced to Archidekt" without sending anything. "Add category" on the same tab has no action. [Confirmed: `src/components/StrategyTab.tsx` lines 412-441, 596-603]
6. **67 source files (about 9,990 lines, whole app, most of it in the deck area) are not reachable from any page**, mostly the old deck header, old status controls, old footer health strip, deck chat tab and parts of the brew screen. About 35 API routes have no live caller; 7 of those are the whole older "AI brew" flow (`api/ai/brew/*`). Section 2.
7. **Backlog and code disagree in several places** (section 1, "Notes vs code" column; summary in section 4). Biggest: the backlog says header/slot-bar/footer-health work (UX-04, UX-11, UX-14) is still to do while the left rail already replaced all three; HC-01/HC-02 deck-health work is listed PROPOSED but is built and live; D-059 (new deck states "Unowned cards", "Use proxies" toggle) is a locked decision that is not built; Brew Canvas (T-08/T-09) is listed PARKED yet about 7,000 lines of it exist and are mounted.
8. **The in-app AI chat is hidden behind one switch** (`NEXT_PUBLIC_AI_CHAT_ENABLED`, per DV-03/D-063). It is not set in the local `.env.local`. Everything marked "behind a switch" below is invisible unless that is set to `true`. I could not see the Vercel setting.
