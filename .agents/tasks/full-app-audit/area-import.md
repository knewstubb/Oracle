Area: every import path, identifier resolution, auth, settings, and the Card Kingdom / Scryfall / EDHREC / Commander Spellbook / Archidekt / Moxfield integrations (src/lib, src/app/api, the pages that use them).
Audit date: 2026-11-26. Branch main, HEAD at "docs: point live references to backlog.md and backlog-details.md". Read-only: nothing in the repo was changed except this file.
Method: import graph built with a throwaway script in /tmp (resolves `@/`, relative and dynamic-looking imports across src, scripts, tests; test importers counted separately), route callers by literal and template-string search of src, scripts, e2e; git log for dates; notes in docs/oracle read against code. No knip/ts-prune was run (the script gave the same answer for this area and needed no install).
Tags: [Confirmed: path] = I opened the file or ran the search. [Approximate] = inferred.
Note on names: the notes use "Sleeved/Unsleeved" in older files and "In deck/Planned" since 2026-11-17; code now uses the newer words.

## 0. Headlines (for whoever writes the owner summary)

1. **One importer is the real one**: the ManaBox-style review screen. It handles file upload, pasted text, deck links (Archidekt, Moxfield, MTGGoldfish, TappedOut, Deckbox) and the Precon tab, for both collection and decks. LIVE and used.
2. **A second, older importer is still in the app**: the "Bring your collection over" onboarding page (Archidekt/Moxfield account import, Brew/Active toggle, conflict screen). It is only reachable from the home page when the account has no decks. The owner's own cleanup brief (import-cleanup, slice 7) says to retire it. It is about 6,800 lines (35 files incl. tests) and was last touched 2026-10-23 (reconciliation UI 2026-10-05).
3. **The old "three choices after a link" screen is still in the code but can never appear.** Since T-63 (2026-10-23) links go into the new review, and nothing ever sets the data that screen needs. About 100 lines of screen plus the server modes behind it. [Confirmed: src/components/DeckImportButton.tsx, `setPreviewData` is only ever called with null (lines 133, 470)]
4. **Notes and code disagree on import more than anywhere else.** backlog-details has no rows for T-59, T-60, T-61, T-62, T-63 (import formats, intent, precons, links, simplified review) although all are merged and in decisions D-054 to D-058. T-58 is "PARKED, not started" but was merged 2026-11-02. The import-cleanup brief still says "DRAFT, nothing deleted" but slices 1, 2 and 4 were done on 2026-10-23.
5. **Settings "Clear All Data" cannot work on the hosted app.** The button is always shown, but the route it calls answers "Not available in production". [Confirmed: src/app/api/dev/reset/route.ts line 12; src/app/settings/page.tsx]
6. **Card Kingdom is fully gone** (D-040 and T-47 agree with the code).
7. **Commander Spellbook and EDHREC "chat tool" paths are only reachable through the paused in-app chat** (D-063 switch), so those client files are currently dormant. EDHREC is live through Deck health commander targets.
8. **Public, unauthenticated endpoint worth a look**: `/api/cards/search` is open without login, uses the all-access database key, and accepts a `deckId` from the caller (it returns only commander colour identity influence on ranking, no card lists). Reported under Auth; not changed.
