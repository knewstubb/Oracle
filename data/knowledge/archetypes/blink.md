# Blink / Flicker

## Overview

Blink (also called flicker) is an archetype built around exiling your own permanents and returning them to the battlefield. When a permanent re-enters, it's a new object with no memory of its past — triggering all enter-the-battlefield (ETB) abilities again. The deck accumulates value by repeatedly blinking creatures with powerful ETBs.

## Core Strategy

1. Play creatures with valuable ETB abilities
2. Use blink effects to exile and return them
3. Generate massive value through repeated triggers
4. Win through overwhelming card advantage, tokens, or combo

## Blink vs Flicker Terminology

- **Blink**: Exile and return immediately (Cloudshift, Restoration Angel)
- **Flicker**: Exile and return at end of turn (Conjurer's Closet, Thassa, Deep-Dwelling)
- **Bounce**: Return to hand, not exile (different strategy, requires recasting)

Both are often used interchangeably, but the timing difference matters:
- Instant return: Can protect from removal, get immediate triggers
- End of turn return: Removes blockers for your turn, one trigger per blink

## Key Synergies

### ETB Value Creatures

**Card Advantage**
- Mulldrifter — Draw 2 cards
- Wall of Omens / Wall of Blossoms — Draw 1 card
- Cloudblazer — Draw 2, gain 2 life
- Spirited Companion — Draw 1 (enchantment creature)

**Removal**
- Ravenous Chupacabra — Destroy target creature
- Skyclave Apparition — Exile nonland permanent CMC 4 or less
- Reflector Mage — Bounce creature, can't cast it next turn
- Angel of Despair — Destroy any permanent

**Ramp**
- Solemn Simulacrum — Fetch basic, draw on death
- Farhaven Elf — Fetch basic to battlefield
- Knight of the White Orchid — Plains if behind on lands
- Dockside Extortionist — Treasures for opponent artifacts/enchantments

**Tokens**
- Avenger of Zendikar — Plant tokens equal to lands
- Myr Battlesphere — Four 1/1 Myr tokens
- Emeria Angel — Flying token on landfall (combo with land ETBs)

**Disruption**
- Agent of Treachery — Steal permanent (draw if control 3+ stolen)
- Drannith Magistrate — Stops opponents casting from non-hand
- Venser, Shaper Savant — Bounce spell or permanent

### Blink Enablers

**Instant-Speed (Reactive)**
- Cloudshift — W, target creature you control
- Ephemerate — W, rebound (free second blink)
- Eerie Interlude — Exile any number, return at end
- Ghostway — Exile all your creatures, return at end

**Repeatable (Engines)**
- Thassa, Deep-Dwelling — Blink at end step
- Conjurer's Closet — Blink at end step
- Brago, King Eternal — Combat damage blinks all nonland
- Soulherder — Blink at end step, grows when things enter

**Creatures that Blink**
- Restoration Angel — Flash, blinks non-Angel
- Felidar Guardian — Blinks any permanent (combo piece)
- Charming Prince — Blinks or other modes

### Infinite Combos

**Felidar Guardian + Kiki-Jiki**
- Kiki-Jiki copies Felidar
- Token blinks Kiki-Jiki
- Kiki untaps, repeat for infinite hasty tokens

**Deadeye Navigator + Dockside Extortionist**
- If Dockside makes 7+ Treasures, go infinite
- Soulbond, pay 1U to blink Dockside
- Repeat for infinite mana and ETB triggers

**Peregrine Drake + Deadeye Navigator**
- Drake untaps 5 lands on ETB
- Pay 1U to blink Drake
- Net 3 mana per loop for infinite mana

### Blink Synergy Cards

**Panharmonicon** — Doubles ETB triggers (not blinks, but doubles results)
**Yarok, the Desecrated** — Same effect in Sultai
**Teleportation Circle** — Cheap repeatable blink
**Essence Flux** — 1 mana blink that adds +1/+1 counter to Spirits

## Building Tips

1. **ETB density** — At least 20-25 ETB creatures to ensure targets
2. **Blink redundancy** — Multiple blink sources so one removal doesn't stop you
3. **Curve considerations** — ETB creatures are often 3-5 CMC; need early ramp
4. **Instant-speed blinks** — Double as protection from removal
5. **Include finishers** — Value is great, but need ways to close games

## Common Pitfalls

- **Too much setup** — Blink enabler but nothing to blink
- **No protection** — Enablers get removed before you untap
- **Slow win conditions** — Grinding value but not actually winning
- **Ignoring non-creature ETBs** — Artifacts and enchantments have ETBs too

## Synergy Partners

Blink pairs well with:
- **Tokens** — Avenger of Zendikar, creature tokens from ETBs
- **Landfall** — Bounce lands, extra land drops
- **Counters** — +1/+1 counter ETBs, proliferate
- **Clones** — Blink clones to copy new targets

## Meta Considerations

- **Power Level**: Scales from casual to competitive (Dockside combos)
- **Speed**: Mid-to-late game; needs setup time
- **Weakness**: Torpor Orb, Hushbringer, Containment Priest, Stifle effects
- **Strength**: Flexible, grindy, can pivot between value and combo

## Anti-Blink Cards to Watch For

- **Torpor Orb** — Shuts down ETB triggers
- **Hushbringer** — Same effect on a creature
- **Containment Priest** — Exile creatures entering not from hand
- **Stifle / Disallow** — Counter triggered abilities
- **Grafdigger's Cage** — Stops some reanimation blink combos
