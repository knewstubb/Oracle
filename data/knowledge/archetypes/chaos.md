# Chaos

## Overview

Chaos decks maximize randomness and create unpredictable game states. Rather than optimizing for wins, chaos players create memorable moments and wild board states that don't happen in typical games.

## Core Strategy

**Philosophy:** Embrace randomness. The goal is creating interesting, memorable game states rather than consistent victories. Chaos players enjoy the journey more than the destination.

**Key Elements:**
- Random effects (coin flips, dice rolls)
- Symmetrical chaos effects
- Board-scrambling spells
- Theft and copy effects
- Cards that affect all players equally

**Note:** Check with your playgroup before building chaos. Many players find it frustrating, and chaos decks can extend games significantly.

- [[Warp World]] — Shuffle everything, flip new permanents
- [[Scrambleverse]] — Redistribute all permanents randomly
- [[Thieves' Auction]] — Draft all nonland permanents
- [[Dimensional Breach]] — Phases out everything, returns slowly

## Building Tips

1. **Ask your playgroup first** — Chaos isn't for everyone
2. **Include some win conditions** — Games need to end eventually
3. **Run cards that benefit you from chaos** — [[Krark's Thumb]], [[Goblin Welder]]
4. **Keep land count high** — Chaos effects are expensive
5. **Include instant-speed interaction** — Chaos doesn't mean no defense
6. **Have a "mercy" plan** — Know when to let the game end

## Common Pitfalls

- **No win condition** — Chaos that never ends isn't fun
- **Extending games too long** — 4-hour chaos games aren't memorable, they're exhausting
- **Ignoring table mood** — Read the room, end games when needed
- **Symmetric effects hurting you more** — Build asymmetry where possible
- **No board control** — Chaos doesn't stop [[Craterhoof Behemoth]]

## Synergy Partners

Chaos pairs well with:
- **Theft** — [[Confusion in the Ranks]] + ETB value
- **Tokens** — Fodder for random sacrifice effects
- **Coin flips** — Dedicated flip payoffs
- **Group slug** — Punish everyone equally

## Meta Considerations

**Strong against:**
- Linear combo (disrupts sequencing)
- Tutor-heavy decks (randomness counters consistency)

**Weak against:**
- Focused aggro (they don't care about board state)
- Fast combo (they win before chaos matters)
- Resilient value decks (they benefit from chaos too)

**Bracket 1-2:** Fun in casual pods
**Bracket 3-4:** Generally not recommended
**cEDH:** Not viable

**Social Contract:** Always discuss before playing. Some tables love chaos, others hate it.
