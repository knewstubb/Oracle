# Enchantress

## Overview

Enchantress strategies leverage enchantment-specific card draw effects to chain enchantments together, generating overwhelming card advantage. The archetype combines this draw engine with enchantment-based control, creature enhancement, or constellation triggers for value and wins.

## Core Strategy

Enchantress operates on a draw engine:
1. **Deploy enchantresses** — Creatures that draw on enchantment cast
2. **Chain enchantments** — Each enchantment draws into more enchantments
3. **Build lock/value** — Enchantments create advantageous board state
4. **Win** — Through enchantment payoffs or overwhelming value

### The Enchantress Engine

Multiple enchantresses create redundancy:
- 1 enchantress = good card advantage
- 2 enchantresses = drawing 2 per enchantment
- 3+ enchantresses = deck-drawing potential

## Building Tips

1. **4-6 enchantresses minimum** — Need consistency for engine
2. **Low curve enchantments** — Chain more efficiently
3. **Protection** — [[Greater Auramancy]], [[Sterling Grove]]
4. **Include removal** — [[Oblivion Ring]], [[Imprisoned in the Moon]]
5. **Win conditions** — Don't just draw cards; include finishers

## Common Pitfalls

1. **Too few enchantresses** — Engine needs redundancy
2. **All draw, no action** — Need enchantments that do something
3. **No protection** — Enchantresses are removal magnets
4. **Missing recursion** — Enchantments get destroyed; bring them back
5. **Ignoring creatures** — Need some board presence

## Synergy Partners

Enchantress pairs well with:
- **Tokens** — [[Sigil of the Empty Throne]], constellation tokens
- **Auras** — Voltron enchantress hybrid
- **Pillowfort** — Many pillow fort pieces are enchantments
- **Lifegain** — [[Sythis]] and related effects

## Meta Considerations

- **Enchantment removal** — [[Bane of Progress]] is devastating
- **Stax** — Many stax pieces are enchantments; natural fit
- **Board wipes** — Enchantments survive creature wipes
- **Counterspells** — Can counter enchantments; use protection
- **Graveyard hate** — Hurts [[Replenish]] strategies

## Constellation Builds

Constellation triggers on ANY enchantment entering:
- Includes tokens like [[Shark Typhoon]]
- Works with blinking enchantment creatures
- [[Opalescence]] + enchantment ETB = double trigger

### Key Constellation Cards
- [[Eidolon of Blossoms]] — Card advantage
- [[Archon of Sun's Grace]] — Token generation
- [[Doomwake Giant]] — Board control
- [[Forgeborn Oreads]] — Damage

### Maximizing Triggers
- Blink enchantment creatures
- [[Starfield of Nyx]] animates then can flicker
- Token enchantments count

This creates voltron/enchantress hybrid potential.
