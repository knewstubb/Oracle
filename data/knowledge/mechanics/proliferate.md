# Proliferate

## Overview

Proliferate lets you add counters to any number of permanents and players that already have counters. This versatile mechanic works with +1/+1 counters, poison, loyalty, charge counters, experience counters, and more.

## Core Strategy

**Philosophy:** Start counters, then multiply them. A single counter becomes lethal with enough proliferate triggers. Works across multiple strategies—planeswalkers, poison, +1/+1 counters, sagas.

**Key Elements:**
- Counter-generating cards
- Repeatable proliferate sources
- Multiple counter types for flexibility
- Planeswalker synergies
- Poison as alternate win condition

## Building Tips

1. **Start counters on multiple permanents** — Proliferate hits all
2. **Include planeswalkers** — Loyalty is a counter type
3. **Consider poison backup** — One counter + proliferate wins
4. **Run Deepglow Skate** — Instant ultimate planeswalkers
