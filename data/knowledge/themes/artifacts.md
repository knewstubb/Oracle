# Artifacts

## Overview

Artifact-focused decks treat artifacts as the primary card type. The theme involves artifact synergies, cost reduction, and leveraging artifact count for powerful effects like affinity, metalcraft, and improvise.

## Identity

When artifacts is your **theme**, you're building around artifact density and synergies. When you run Sol Ring and a few other rocks, artifacts are incidental.

## Core Mechanics

- **Affinity** — Costs less for each artifact you control
- **Metalcraft** — Bonuses when you control 3+ artifacts
- **Improvise** — Tap artifacts to pay for spells
- **Artifact Recursion** — Return artifacts from graveyard

## Key Synergy Patterns

### Artifact Cost Reduction
Make artifacts cheaper, deploy more, repeat.
- Foundry Inspector + cheap artifacts = explosive turns
- Etherium Sculptor + Jhoira, Weatherlight Captain = draw engine

### Artifact ETB Payoffs
Each artifact entering triggers value.
- Reckless Fireweaver — 1 damage per artifact
- Sai, Master Thopterist — 1/1 thopter per artifact

### Eggs/Cheerios
Zero-cost artifacts cycle through the deck.
- 0-mana artifacts + Jhoira = draw through deck
- Krark-Clan Ironworks + recursion = infinite mana

## Common Mistakes

1. **No protection** — Vandalblast destroys artifact decks. Run Darksteel Forge
2. **Too many rocks, not enough payoffs** — Ramp without direction
3. **Ignoring recursion** — Artifacts die. Plan to get them back
4. **Mana curve too high** — Affinity needs cheap artifacts to enable

## Compatible Archetypes

- **Combo** — Eggs, KCI loops, Aetherflux
- **Aggro** — Affinity, cheap artifacts, fast damage
- **Control** — Value artifacts, recursion engine
