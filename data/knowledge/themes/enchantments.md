# Enchantments

## Overview

Enchantment-focused decks treat enchantments as the primary card type. The theme involves enchantress draw engines, constellation triggers, and building a fortress of synergistic enchantments.

## Identity

When enchantments is your **theme**, you're building around enchantment density and payoffs. When you run a few good enchantments, it's incidental.

## Core Mechanics

- **Enchantress** — Draw a card when you cast an enchantment
- **Constellation** — Triggers when an enchantment enters (cast or token)
- **Aura Synergies** — Auras that boost creatures or recur
- **Enchantment Tokens** — Sagas, roles, etc.

## Key Synergy Patterns

### Enchantress Engine
Each enchantment draws a card, enabling chains.
- Enchantress's Presence + cheap enchantments = draw engine
- Setessan Champion — draw + counters

### Constellation Value
Each enchantment entering (not just cast) triggers.
- Doomwake Giant — -1/-1 to opponents' creatures
- Archon of Sun's Grace — 2/2 pegasus per enchantment

### Enchantment Recursion
Return enchantments for repeated value.
- Replenish — mass recursion
- Starfield of Nyx — return each upkeep

## Role Categories

| Role | Examples |
|------|----------|
| Enchantress Draw | Argothian Enchantress, Enchantress's Presence, Eidolon of Blossoms |
| Constellation | Archon of Sun's Grace, Doomwake Giant, Setessan Champion |
| Finishers | Starfield of Nyx, Opalescence, Sigil of the Empty Throne |

| Recursion | Replenish, Open the Vaults, Dance of the Manse |

## Common Mistakes

1. **Not enough enchantments** — Enchantress needs density. Run 30+ enchantments
2. **No draw engine** — Without enchantress effects, the deck runs out of gas
3. **Ignoring creature count** — Some enchantments need creatures to target
4. **All value, no win** — Build toward a finish (Sigil tokens, Opalescence beats)

## Compatible Archetypes

- **Control** — Pillowfort enchantments + value
- **Midrange** — Constellation value engine
- **Combo** — Enchantment-based combos (Parallax Wave, etc.)
