# Tokens

## Overview

Token decks create and multiply creature tokens, then convert quantity into quality through anthems, sacrifice, or overrun effects. The theme is fundamentally about going wide.

## Identity

When tokens is your **theme**, the deck is built around token generation and payoffs. When you make occasional tokens (Elspeth in superfriends), it's incidental.

## Core Mechanics

- **Token Generation** — Create creature tokens at scale
- **Token Doublers** — Parallel Lives, Anointed Procession, Doubling Season
- **Anthems** — Buff all your creatures
- **Go-Wide Finishers** — Craterhoof, Triumph of the Hordes

## Key Synergy Patterns

### Doubler + Token Generator
Each token makes two (or four with multiple doublers).
- Parallel Lives + Avenger of Zendikar
- Anointed Procession + Bitterblossom

### Tokens + Aristocrats
Tokens are sacrifice fodder.
- Token generators + Blood Artist + sac outlet
- Chatterfang — every token makes an extra squirrel to sacrifice

### Go-Wide → Lethal
Convert board presence into kills.
- Craterhoof Behemoth — +X/+X and trample
- Triumph of the Hordes — infect for instant poison kills

## Role Categories

| Role | Examples |
|------|----------|
| Generation | Avenger of Zendikar, Bitterblossom, Krenko |
| Doublers | Parallel Lives, Anointed Procession, Doubling Season |

## Budget Alternatives

| Premium | Budget | Notes |
|---------|--------|-------|
| Doubling Season ($50) | Parallel Lives ($15) | Tokens only, no counters |
| Craterhoof Behemoth ($30) | End-Raze Forerunners ($0.50) | Slightly weaker but same effect |
| Anointed Procession ($25) | Mondrak ($10) | Creature, can be removed easier |

## Common Mistakes

1. **No protection from wipes** — One Wrath ends you. Run Heroic Intervention
2. **Too slow** — Token decks need to threaten before opponents stabilize
3. **No finisher** — 20 1/1s don't kill 3 opponents. Run Craterhoof effects
4. **Ignoring anthems** — 20 1/1s < 20 3/3s

## Compatible Archetypes

- **Go-Wide Aggro** — Fast token pressure
- **Aristocrats** — Tokens as sacrifice fodder
- **Combo** — Infinite token combos (Kiki-Jiki, etc.)
