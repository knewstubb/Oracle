# Treasure

## Overview

Treasure decks treat treasure tokens as more than just mana — they're artifacts, sacrifice fodder, and synergy enablers. The theme involves generating treasures at scale and converting them into wins through artifact or sacrifice synergies.

## Identity

When treasure is your **theme**, you're building around treasure generation and payoffs. When you just make occasional treasures for ramp (Dockside once), treasure is incidental.

## Core Mechanics

- **Treasure Generation** — Create treasure tokens at scale
- **Artifact Count** — Treasures count as artifacts for affinity, metalcraft, etc.
- **Sacrifice Triggers** — Treasures dying triggers aristocrats effects
- **Mana Burst** — Crack multiple treasures for explosive turns

## Key Synergy Patterns

### Treasure + Artifact Synergy
Each treasure is an artifact ETB and artifact death.
- Reckless Fireweaver — 1 damage per treasure created
- Marionette Master — 4 damage per treasure sacrificed
- Academy Manufactor — each treasure makes food and clue too

### Treasure + Sacrifice
Treasures are free sacrifice fodder.
- Korvold + treasures = draw and counters
- Mayhem Devil + treasures = 1 damage per sacrifice

### Treasure Storm
Generate treasures, crack them all for big mana, storm off.
- Dockside + Temur Sabertooth = infinite treasures (with enough artifacts/enchantments)
- Storm-Kiln Artist + cheap spells = treasure per spell

## Common Mistakes

1. **Just ramping** — If you only crack treasures for mana, you're not maximizing the theme
2. **No artifact synergies** — Treasures are artifacts. Run artifact payoffs
3. **Ignoring colors** — Treasures make any color. Build greedy mana bases
4. **Forgetting death triggers** — Each treasure sacrifice can trigger aristocrats effects

## Compatible Archetypes

- **Aristocrats** — Treasures as sacrifice fodder
- **Combo** — Dockside loops, storm turns
- **Midrange** — Treasure as value and ramp
- **Artifacts-matter** — Treasure counts for affinity, metalcraft
