# Phoenixes

## Overview

Phoenixes are red's iconic recursive flyers. They die and return repeatedly, making them excellent for graveyard strategies and sacrifice-based builds. Phoenix tribal values resilience over raw power.

## Color Identity

- **Primary**: Red
- **Secondary**: None
- **Common Pairs**: Mono-red, Rakdos (BR), Izzet (UR)

## Key Mechanics

- **Recursion**: Return from graveyard
- **Flying**: Universal evasion
- **Haste**: Common keyword
- **Death Triggers**: Benefits from dying

## Signature Cards

### Recursive Phoenixes
- Rekindling Phoenix — Returns with egg token
- Arclight Phoenix — Returns on 3 instants/sorceries
- Phoenix of Ash — Escape from graveyard
- Flamewake Phoenix — Ferocious return

### Other Notables
- Everquill Phoenix — Mutate phoenix
- Ashcloud Phoenix — Morph and return
- Kuldotha Phoenix — Metalcraft return

### Support
- Feldon of the Third Path — Copy in graveyard
- Chandra, Flamecaller — Discard and draw

## Common Commanders

- **Syrix, Carrier of the Flame** — Phoenix tribal payoffs
- **Feldon of the Third Path** — Reanimation theme
- **Neheb, Dreadhorde Champion** — Discard synergy

## Synergy Partners

Phoenixes pair well with:
- **Spellslinger** — Arclight Phoenix
- **Aristocrats** — Repeated deaths
- **Self-Mill** — Fill graveyard
- **Discard** — Cycle and return

## Build Notes

Phoenix tribal is shallow but flavorful. Most builds combine phoenix creatures with spellslinger or aristocrats strategies.
