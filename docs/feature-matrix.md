## Summary Scoring

### Feature Completeness (MVP Scope)
- **Archidekt**: 32/40 (80%) — Strong foundational feature set
- **Moxfield**: 38/40 (95%) — Most feature-complete
- **Manabox**: 28/40 (70%) — Minimal but functional
- **The Oracle**: 28/40 (70%) — On track for MVP parity

### Differentiation (Phase 2+)
- **The Oracle**: Commander insights, collection allocation, deck composition analysis (3 unique areas)
- **Competitors**: Playtest simulator, collaboration, public sharing (overlapping)

### Competitive Positioning
1. **On parity**: Card search (need +3 filters), pricing display, basic analysis
2. **Differentiated**: Commander-specific insights and sophisticated collection model
3. **Intentionally deferred**: Public sharing, collaboration, playtest (personal-app scope)

## Key Takeaway

**The Oracle is competitive at MVP with three Phase 1 additions** (mana cost filter, P/T filter, price display). Differentiation comes from **Commander-specific features in Phase 2**, not from copying Moxfield's breadth.
