1e · Setup guide (plain words)
Settings · Claude connector

Set up Claude

i
Start on the web or desktop. The phone app can't add a new connector yet; once you add it on the web or desktop it shows up on your phone.

Your connector address (copy it):

https://oracle.example.com/connector

Claude on the web
  1. Open Claude and go to Settings → Connectors.
  2. Choose Add custom connector, paste the address above and save.
  3. Choose Connect. Oracle's sign-in opens. Sign in and press Sign in and allow.
  4. Back in a Claude chat, ask "What's in my Korvold deck?"
Claude on the desktop
  1. Open Claude desktop and go to Settings → Connectors.
  2. Add the custom connector with the address above.
  3. Sign in to Oracle when asked.
Claude on the phone
  1. First add Oracle on the web or desktop (steps above).
  2. Open the Claude app on your phone. Oracle appears in the connectors list.
  3. Switch it on for the chat you are in, then ask your question.
Claude Code
  1. In your terminal, run the command below. Replace the name if you like.
    2. claude mcp add --transport http oracle https://oracle.example.com/connector
  2. Start Claude Code, choose /mcp, pick Oracle and sign in.

Claude's menus change from time to time. If a step looks different, look for "connectors" in Claude's settings.

4 · Card moved: how it looks in the ORIGINAL deck's plan

No new kind of slot. A moved card's slot in the old deck simply goes back to Unsleeved (a wanted card with no copy in it) and uses the existing Unavailable · In Korvold badge. The only addition is one quiet history line, so the owner can tell "Claude moved it" from "it was never here".

5 · What Claude can and can't do

A short panel at the bottom of the Connection tab (and linked from the sign-in screen). It is the only place the limits are spelled out. Note what is missing from every screen above: there is no "remove from collection" action in Claude's changes, in pending approvals or in the deck views it touches.

5 · Panel

What Claude can and can't do

Claude can
  • ✓Read your decks, collection and where each card is
  • ✓Add and take cards off a deck list (the copy goes back to storage, never deleted)
  • ✓Move a card to or from a maybeboard
  • ✓Add a card to your collection
  • ✓Mark a copy Original or Proxy
  • ✓Make small changes straight away. You can undo them here for 7 days
Claude can't
  • ✕Take any card out of your collection
  • ✕Delete or empty a deck
  • ✕Clear or replace your collection
  • ✕Do big edits (over about 10 cards) or move a card between decks without your yes here
  • ✕Approve its own waiting changes
  • ✕See anyone else's data

These limits are enforced by Oracle, not by Claude's own prompts, so they hold even if Claude is set to never ask.
