Rename a deck and reorder decks

Gate 3 mockup for UX-05 and UX-03. It works: drag tiles, drop them on folder chips, click a deck name to rename it. Everything uses the colours, tile, folder chip and message style the app already has. Fake data; nothing is saved.

Try this
  1. Reorder. Drag a tile. A dashed "Drop here" spot shows where it will land and the other tiles slide aside.
  2. Folder or order? Drag the same tile over a folder chip. The chip lights up purple and says "Drop to file here". Over the tiles you only see the dashed spot. Never both.
  3. Group: Status. Switch the group menu to "Group: Status", then drag a Playable tile into the Assembling group. It is refused and goes back.
  4. Folder open. Click a folder chip. Tiles no longer reorder, and a note says so. Dropping on another folder chip still files the deck.
  5. Failure. Tick "Make the next save fail", then reorder or rename. The old order or name comes back with a message.
  6. Rename. Click a deck name (on a tile or in the deck page strip at the bottom). Enter or clicking away saves. Escape cancels. Try an empty name, or "prosper" while a deck called "Prosper" exists.
