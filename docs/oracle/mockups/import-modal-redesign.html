Import built deck · redesigned modal

Everything below is the real modal, working on sample data. Try: pick a source deck for each Sol Ring copy (the warning and the “need attention” chip clear as you go), rename the deck to clear the duplicate-name warning, change the commander to see Partner / Background appear, switch “Ignore basic lands”, expand rows. The sample cards and decks are illustrative, not real data.

Icon key

ICON_PROXY Proxy — teal, filled mask (existing icon)
ICON_PULLED Pulled from another deck — violet, outlined card with an arrow leaving it. A number appears when the row has 2+ copies.
ICON_WARN Needs attention — amber triangle, always with words in the badge or bar.

What the sample shows

  • Sol Ring ×2: both copies could come from two different decks, so each copy has its own picker. Unresolved at first.
  • Arcane Signet ×2: one spare copy + one pulled from Korvold (mixed row: badge “Mixed”, icon with 1).
  • Command Tower, Snow-Covered Forest: single pulled copy, chosen automatically.
  • Rhystic Study: a new Proxy. Smothering Tithe: unowned, list only.
  • Eternal Wtiness: not matched, so it needs a decision.

Screen sizes

Large: the modal is 88% of the screen height. Laptop (under 800px usable height): the modal fills the screen minus a 16px margin on every side. Only the card list scrolls; the header, warnings bar and footer stay in view.
