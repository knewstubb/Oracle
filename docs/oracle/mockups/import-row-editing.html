Import screen — row editing

Mockup rev 1. Everything below is live: tick boxes, press Edit, change values, press Change on the defaults bar. Data is sample only. Card list pieces only; the rest of the import dialog is unchanged.

1 · Defaults bar (sits above the list)

One line. Values the file supplies (ManaBox condition, language, foil) win per card, so they never need re-entering.

2 · Collapsed rows — default, with tags, mixed

Rows 1–2 are plain. Row 3 has one tag. Row 4 is foil from the file. Row 5 is mixed (3 copies, each different): tags count the exceptions. Row 6 is a Japanese-language card. The Original/Proxy counters are gone; Edit is the only control on the right.

3 · One expanded row (Rehearsed Debater ×3, the owner's example)

Edit splits the row into one line per physical copy. Copy 2 is a Proxy, so only Language is shown. A small dot marks a value that came from your file (hover for “From your file”); changing that value clears the dot. The number of copies is fixed by the file; you only edit each copy's attributes. Try switching a copy to Proxy, and the small ⇊ icon on copy 1, which copies its settings to all copies.

4 · Bulk action bar (rows ticked)

Ticking rows swaps the list header for the bulk bar; here Rehearsed Debater is ticked, so the type shows “Mixed”. “Set finish / condition / language” opens a small panel; each field defaults to “Leave as is”. Open it to preview.
