## Assumptions
- "JSON sidecar block" in D-016 means a dedicated, unambiguous JSON payload, not a markdown-fenced JSON object buried in prose that must be located with regex/string replacement. Routes that strip markdown fences and parse JSON from free-form model text were therefore judged Mismatch.
- Regex applied to **user input** (e.g., intent detection in `src/app/api/oracle/chat/route.ts`, collection-type detection in `src/lib/tool-executor.ts`) was not counted as a D-016 violation because D-016 targets structured data **from LLMs**, not preprocessing of user messages.
- Routes under `src/app/api/ai/brew/` that do not invoke an LLM (`session`, `confirm`, `save`) were classified as "N/A — not an AI call" rather than Matches/Mismatch.
