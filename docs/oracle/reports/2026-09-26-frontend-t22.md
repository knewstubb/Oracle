## Assumptions

- The Backend will implement the routes defined in `docs/oracle/contracts/import-reconciliation-redesign.md` §4.1 before the UI is exercised end-to-end.
- The contract's `GET /api/onboarding/reconciliation` returns `ReconciliationView`; the UI does not compute supply or over-allocation locally.
- The contract's `PATCH` mutation responses return `{ view: ReconciliationView }` (printing mutation also returns `demoted`), and the UI replaces local state with the response view.
- `alternatePrintings` is empty for unowned rows, so the select only appears on owned rows, matching spec §12.
- Native `<img>` is used for card thumbnails, consistent with existing components (`PicklistV2`, `StatusChipPopover`) and the existing hover-preview implementation.
