## New decisions made (need owner confirmation)
- The overflow descriptor for a card whose owned copies are already sleeved elsewhere is `Already claimed` (amber warning label), not `Planned (used elsewhere)`.
- Tab counts are per **conflict printing**, not per deck-card instance. One card in 20 decks with the same printing is one conflict.
- In the Decks tab, when a card is "Already claimed", the row shows the deck(s) that own the real copy.
- Owned and Unowned tabs use the same card-container layout as the Decks tab, with instance controls (state buttons, printing select, wishlist checkbox) aligned to the right.
- Alternate-printing conflicts warn only; they do not block finishing.
- Wishlist deck tags are not clickable.
- Resolved printings stay in place; there is no separate "Resolved" section.
- There is no tie-breaker for competing owned copies; the UI prevents more instances being Sleeved than copies owned.
- Resolved printings remain visible until the screen is refreshed or reloaded.
