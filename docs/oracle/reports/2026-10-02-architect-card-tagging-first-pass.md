# Assistant first pass: 100-card review set

**Status:** Draft labels for owner review. These are suggestions based on each card's rules text, not final answers and not Haiku results. Please accept, edit, or mark each as unsure. Scryfall/Haiku comparisons should stay hidden until the owner-confirmed descriptions are locked.

The phrasing is intentionally plain. It names the action, what it affects, and any condition that could change whether the card fits a deck. A card may have several labels. “No distinct mechanic” is a deliberate empty result, not a missing review.
