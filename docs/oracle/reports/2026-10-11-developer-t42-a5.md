## Real defects found but deliberately not fixed (per task instructions)
Each entry says what the type checker shows and why it is a bug, not a typing quirk. I did not change runtime behaviour.

1. **Commander taxonomy search filters on columns that do not exist** — `src/app/api/commanders/search/route.ts:130,143,162`. The query filters `ref_commander_taxonomy` by `tag_type`/`tag_value` and orders by `deck_count`; that table only has `id, commander_id, taxonomy_slug, relevance, source, confidence, created_at` (`supabase/migrations/20260803100000_create_ref_taxonomy.sql:30`). Filtering a commander search by archetype/theme/tribe therefore errors or returns nothing. Fix: join `ref_taxonomy` on `taxonomy_slug` and filter `category`/`display_name` (Architect/Developer).
2. **Session name generation always fails** — `src/app/api/oracle/sessions/[id]/generate-name/route.ts:120`. Calls `adapter.generateText()`, but `ProviderAdapter` only defines `sendMessage`/`sendMessageStreaming` (`src/lib/provider-adapter.ts:95`). The route throws and returns 500; auto-naming a chat never works.
3. **Deck health pills do nothing** — `src/app/decks/[id]/page.tsx:356`. `<HealthStrip deckId={...} />` omits the required `onPillClick`. A `handlePillClick` exists at line 159 but is never wired, so tapping a health pill has no effect.
4. **new-deck page reads `session.committedCommander`** — `src/app/new-deck/page.tsx:116,119,124`. `BrewSessionState` stores the commander as `commander`, not `committedCommander`. The Oracle side-panel context therefore never switches to "workbench".
5. **new-deck page references out-of-scope `params`** — `src/app/new-deck/page.tsx:310`. `params` is a local inside a different effect; here it is undefined, so session creation throws and the `commander` URL parameter is never applied.
6. **new-deck page references undefined `chatHandleRef`** — `src/app/new-deck/page.tsx:769`. "Discuss this card" throws a ReferenceError.
7. **Invalid ownership state `'unknown'`** — `src/app/new-deck/page.tsx:810,994`. Writes `ownership_status: 'unknown'`, which is not one of `original | proxy | not_owned | generic` (D-001/D-012).
8. **Wrong handler wired to commander select** — `src/app/new-deck/page.tsx:1155`. Passes `handleCommitCommander` (expects a commander object) to `onSelectCommander` (expects a name string); `handleCommitCommanderFromChat` is the correct handler. Selecting a commander from the detail modal misbehaves.
9. **Status chip: wrong field names and missing preview data** — `src/components/StatusChipPopover.tsx:142,340,434,533,593,601,626,649`. Reads `tier4Confirm.deckName` (field is `holderDeckName`); passes `validDecks` shaped `{isActive}` into a picker that expects `{deckStatus}`; reads `holder.deckStatus` (holders have `isActive`), so the Tier‑3 instant claim never triggers; destructures a non-existent `previewProps` from `useCardHoverPreview`; and references undefined `previewUrl`, breaking proxy hover/download/copy.
10. **Picklist uses retired field names** — `src/components/PicklistV2.tsx:83,374,412,536`. Reads `storageLocationName` and `scryfallPrintingId`; `EnrichedSupplyEntry` exposes `locationName` and `printingId`. Also reads a non-existent `previewProps`, and relies on the deprecated `assignedTo.deckStatus`, which the supply query never populates (it sets `isActive` only). Picklist locations, thumbnails and previews are wrong/empty.
11. **Version history restore modal cannot be cancelled** — `src/components/VersionHistoryPanel.tsx:267`. Passes `onOpenChange`/`variant` (not props of `ConfirmationModal`) and omits the required `onCancel`; the Cancel button and dismiss gesture do nothing.
12. **`asChild` used on components that do not support it** — `src/components/TopNav.tsx:160,255` (`DropdownMenuItem`) and `src/components/DeckPickerPopover.tsx:63` (`PopoverTrigger`). The codebase's base-ui wrappers use `render={...}` for this, not `asChild`; the prop is ignored, so menu links/picker triggers are not rendered as intended.
13. **Deck chat card converter emits obsolete fields** — `src/components/DeckChatTab.tsx:53,54`. `toBrewDeckCard` sets `mana_cost`/`mana_value`, which are not on `DeckCard`, and appears to omit `cmc`/`type_line`/`oracle_text`.
14. **Commander images never load on two screens** — `src/components/CommanderSuggestionCard.tsx:45,46` reads `info.imageUrl`, but `getCardInfo()` returns only `{ scryfallId, canBeCommander }` (`src/components/CardHoverPreview.tsx:388`); `src/components/explore/SuggestedCommanders.tsx:124` calls `CardImage` with `cardName` instead of `scryfallId`/`alt`. `src/components/MobileCardPreview.tsx:68` also passes a nullable `scryfallId` where a string is required (and omits `alt`).
15. **Selected colour ring is never applied** — `src/components/ColorIdentityFilter.tsx:103` sets an invalid `style={{ ringColor }}`; the colour-identity selected ring uses the default colour. Also `src/components/AddCardSearch.tsx:272,278` passes an unsupported `title` prop to lucide icons, so the "Commander"/"Owned" tooltips are not shown.
