Nothing here touched the hosted database. Every run builds a brand-new local Postgres 17 cluster on 127.0.0.1:55434 in a temp folder and deletes it when the script ends.
Run one with `./run.sh <name>` (needs `/opt/homebrew/opt/postgresql@17`). Output is saved next to the script as `<name>.out`.
Same harness as `../cc15-db/` (stand-in base tables in `00_base.sql`, then the REAL migrations 20261116130000 through 20261117200100 applied unmodified, then the draft under test). Added here: a `ref_printings` stand-in, a second and third test user, and helper functions in schema `t` (`t.try`, `t.sub`, `t.und`, `t.fp`, `t.snap`).
