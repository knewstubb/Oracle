Layout Pattern Rationale

Card Grid

Used when visual identity matters. Decks are recognized by commander art. Storage locations are recognized by icons/colors. Grid enables quick scanning of many items.

Grouped List

Default for deck contents. Groups by Type (or Category) map to how players think about decks. Collapsible sections keep large lists manageable. Status chips are the key interactive element.

Image Grid

Alternative deck view for visual browsing. Minimal text, maximum card art. Good for "what's in this deck?" but less useful for allocation work than grouped list.

Action Queue

Task-oriented layout for Picklist. Only shows items needing resolution. Grouped by action type (Pull, Proxy, Buy). Each row has one-click resolution buttons.

Search + Table

Collection is search-first because users rarely browse — they look for specific cards. Autocomplete shows copies and locations before selecting. Table for result density.

Command Palette (Global Search)

⌘K anywhere opens the search. Card image + inline actions for rich experience. Answers "where is card X?" and enables immediate actions (add to deck, wishlist, proxy list).

Diagnostic Table

Shared Cards is analytical — "where am I stretched thin?" Sorted by conflict severity. Visual conflict bars show at-a-glance where to buy duplicates.

View Tabs (ClickUp-style)

Collection has built-in views (All Cards, By Card, Storage, Proxy List) plus user-created saved filters. "+ View" opens a filter builder. Views are persistent tabs, not temporary filters.

Card Management Modal

Opens from "By Card" view (grouped by oracle_id). Shows all copies across printings, all deck slots using this card, and wishlist status. Enables Pull/Assign/Release actions inline. This is the "tell me everything about this card" view.

Key Design Principles

Top Bar Navigation

Main nav lives in the top bar: Logo | Decks | Collection | Wishlist | Tools | Search | Settings | Avatar. Settings (gear icon) and Avatar (initials) are on the far right. Search is centered.

Status Chips as Buttons

Every status chip (Original, Claimed, Proxy, Open, Unowned) is clickable. Shadow, hover state, and cursor signal interactivity. This is the core allocation UX.

Playability is Hero

The most important thing about a deck is "can I play this right now?" Playability badges are prominent on deck cards and in toolbar context.

Remember User Preferences

Group-by, sort, and view mode choices persist. If user switches to Category grouping, that's their default until they change it again.

Global Search Everywhere

Collection search is the primary way to find cards. Autocomplete shows "Card X: 3 copies — 1 in Prosper, 1 in Korvold, 1 in Staples Binder" before selecting.
